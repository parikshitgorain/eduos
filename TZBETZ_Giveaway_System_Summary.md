# TZBETZ Giveaway System - Executive Summary

## What It Does
A complete crypto giveaway reward system that turns stream giveaways into controlled, profitable user engagement while preventing abuse and increasing retention.

## The Flow (Simple Version)

```
Kick Stream Giveaway → TZBETZ Balance → User Choice → Crypto Payout
                                           ↓
                                    TZBETZ Shop (Alternative)
```

## How It Works

### 1. **Giveaway Wins** 🎯
- User wins giveaway during your Kick stream
- Reward automatically credited to their TZBETZ website balance
- **No direct crypto tip** - everything goes through our system first

### 2. **User Has Two Choices** 🛒💰
- **Option A**: Spend balance in TZBETZ Shop (reduces withdrawal pressure)
- **Option B**: Request crypto withdrawal ($5, $10, $20, $100 options)

### 3. **Smart Withdrawal Controls** 🎰
- **Monthly Wager Requirements**: User must wager on Rainbet before withdrawing
  - $5 withdrawal = Low wager requirement
  - $100 withdrawal = High wager requirement
  - Requirements increase over time (prevents abuse)
  - Resets monthly (fresh start each month)

### 4. **Security Layer** 🔒
- **Admin Approval**: Every withdrawal manually reviewed for security
- **Hot Wallet Check**: System verifies crypto funds available
- **Instant Payout**: If approved + funds available = instant Rainbet deposit

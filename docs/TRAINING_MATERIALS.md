## Training Program Overview

### Learning Objectives

By completing the EduOS training program, users will be able to:

1. **Navigate** the platform confidently
2. **Perform** daily tasks efficiently
3. **Understand** security and compliance requirements
4. **Troubleshoot** common issues independently
5. **Leverage** advanced features for their role

- **Self-Paced Online**: Video tutorials and documentation
- **Live Webinars**: Interactive sessions with Q&A

- **Certification Exams**: Validate knowledge and skills

## Quick Start Guides

### Quick Start 1: First Login (5 minutes)

**Objective:** Successfully log in and set up your profile

**Steps:**
1. Navigate to your institution's EduOS URL
2. Enter email and temporary password
3. Change password when prompted
4. Set up multi-factor authentication (MFA)
5. Complete profile information
6. Explore the dashboard

**Success Criteria:**
- ✓ Logged in successfully
- ✓ MFA enabled
- ✓ Profile completed
- ✓ Dashboard visible

### Quick Start 2: Mark Attendance (10 minutes)

**Objective:** Mark attendance for a class

**Steps:**
1. Navigate to Attendance → Mark Attendance
2. Select class/batch
3. Select date (defaults to today)
4. Mark students as Present, Absent, or Late
5. Add notes if needed
6. Submit attendance
7. Verify submission

**Success Criteria:**
- ✓ Attendance marked for all students
- ✓ Submission confirmed
- ✓ Attendance visible in reports

### Quick Start 3: Create a Student (10 minutes)

**Objective:** Add a new student to the system

**Steps:**
1. Navigate to Students → Create Student
2. Fill in required fields:
   - First Name
   - Last Name
   - Date of Birth
   - Email
3. Review duplicate detection results
4. If no duplicates, proceed with creation
5. Enroll student in batch
6. Verify student appears in list

**Success Criteria:**
- ✓ Student created successfully
- ✓ No duplicate records
- ✓ Student enrolled in batch
- ✓ Student visible in list

### Quick Start 4: Generate Invoice (15 minutes)

**Objective:** Create and send an invoice

**Steps:**
1. Navigate to Payments → Invoices → Create
2. Select student
3. Add line items:
   - Description
   - Amount
   - Quantity
4. Configure tax (GST)
5. Set due date
6. Preview invoice
7. Generate and send
8. Verify invoice number sequence

**Success Criteria:**
- ✓ Invoice created with sequential number
- ✓ PDF generated
- ✓ Email sent to student/guardian
- ✓ Invoice visible in list

## Hands-On Exercises

### Exercise 1: Create Your First Tenant

**Difficulty:** Beginner  
**Duration:** 15 minutes  
**Prerequisites:** Admin access

**Scenario:**
You're setting up EduOS for Springfield Elementary School. Create a tenant with appropriate configuration.

**Tasks:**
1. Create tenant with name "Springfield Elementary"
2. Set subdomain to "springfield"
3. Choose Business tier
4. Configure timezone to Asia/Kolkata
5. Set currency to INR
6. Create admin user
7. Verify tenant creation

**Validation:**
- Tenant appears in tenant list
- Admin can log in
- Dashboard shows correct settings

### Exercise 2: Build an Organizational Hierarchy

**Difficulty:** Intermediate  
**Duration:** 20 minutes  
**Prerequisites:** Exercise 1 completed

**Scenario:**
Springfield Elementary has two campuses (North and South), each with multiple programs.

**Tasks:**
1. Create Institute node (auto-created)
2. Create Center: North Campus
3. Create Center: South Campus
4. Under North Campus, create Program: Elementary
5. Under Elementary, create Class: Grade 1
6. Under Grade 1, create Batch: Section A
7. Repeat for South Campus
8. Verify hierarchy tree

**Validation:**
- All nodes created correctly
- Parent-child relationships correct
- Permissions inherited properly

### Exercise 3: Create a Dynamic Student Form

**Difficulty:** Intermediate  
**Duration:** 25 minutes  
**Prerequisites:** Exercise 2 completed

**Scenario:**
Create a student profile form with custom fields and role-based permissions.

**Tasks:**
1. Create schema "Student Profile"
2. Add standard fields:
   - First Name (text, required)
   - Last Name (text, required)
   - Date of Birth (date, required)
   - Email (email, required)
3. Add custom fields:
   - Parent Name (text)
   - Emergency Contact (phone)
   - Medical Conditions (textarea)
4. Set field permissions:
   - Teachers can view all, edit none
   - Admins can view and edit all
5. Preview as Teacher role
6. Publish schema

**Validation:**
- Schema created with version 1.0.0
- All fields configured correctly
- Permissions work as expected
- SHA-256 hash generated

### Exercise 4: Process a Complete Payment Flow

**Difficulty:** Advanced  
**Duration:** 30 minutes  
**Prerequisites:** Payment gateway configured

**Scenario:**
Process a tuition payment from student enrollment to bank reconciliation.

**Tasks:**
1. Create student "John Doe"
2. Enroll in Grade 1, Section A
3. Generate invoice for ₹50,000 tuition
4. Process payment via Razorpay (test mode)
5. Verify webhook received
6. Generate receipt
7. Upload bank statement
8. Reconcile payment
9. Generate financial report

**Validation:**
- Invoice created with sequential number
- Payment processed successfully
- Webhook logged
- Receipt generated
- Bank reconciliation matched
- Report shows payment
